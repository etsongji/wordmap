# 단어 지도 (Word Map) — 반 운영판

학생이 학번·이름으로 접속해 영어 단어의 뜻·유의어·반의어·어근을 입력하면 개인 단어 지도가 만들어지고, 교사는 반 전체 단어를 워드클라우드와 학생별 포트폴리오로 확인하는 웹앱이다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 학생 화면 + 교사 화면. 단일 파일이며 CDN 의존 없이 동작한다. |
| `Code.gs` | Google Apps Script 백엔드. 학생 데이터를 구글 시트 `students`에 저장한다. |

데이터 흐름: 학생 브라우저 → Apps Script 웹앱 → 학교 계정 구글 시트. 외부 서버로 개인정보가 나가지 않는다. 단, 추천·검색 미리보기 기능은 영어 단어만을 Datamuse 공개 사전 API로 조회한다(학생 정보는 전송하지 않음).

## 배포 순서

1. 학교 구글 계정으로 새 스프레드시트를 만들고 확장 프로그램 → Apps Script를 연다.
2. `Code.gs` 내용을 붙여넣는다. 상단의 `TEACHER_PIN`에 교사 비밀번호를 넣는다. 비워 두면 교사 화면에 들어갈 수 없다.
3. 배포 → 새 배포 → 유형 "웹 앱", 실행 계정 "나", 액세스 권한 "모든 사용자"로 배포하고 웹앱 URL을 복사한다.
4. `index.html`의 `API_URL`에 그 URL을 넣는다.
5. `index.html`을 학생이 열 수 있는 곳에 올린다. GitHub Pages나 학교 드라이브 공유 링크 모두 가능하다. HTML 안에는 학생 정보가 없으므로 공개 호스팅해도 된다. 교사 비밀번호는 서버에만 있다.
6. `Code.gs`를 고친 뒤에는 배포 → 배포 관리 → 새 버전으로 다시 배포해야 반영된다.

## 사용법

- 학생: 학번 4자리와 이름을 넣고 시작한다. 처음 입력한 이름이 그 학번에 묶이며, 이후 다른 이름으로 접속하면 거부된다. 단어는 입력 즉시 기기와 서버에 자동 저장된다.
- 교사: 학번 칸에 `teacher`, 이름 칸에 `TEACHER_PIN` 값을 넣는다. 워드클라우드에서 단어를 누르면 어느 학생이 넣었는지 보이고, 포트폴리오에서 학생별 지도를 볼 수 있다. CSV 내보내기는 반별 통계다.
- 이름을 잘못 입력한 학생은 시트 `students`의 B열(이름)을 교사가 직접 고쳐 준다. 시트에서 행을 지우면 그 학생 데이터가 초기화된다.

## 검증 방법 (샘플 데이터)

배포 전 `API_URL`을 비운 채 `index.html`을 브라우저에서 열면 서버 없이 동작한다.

1. 학번 `2103`, 이름 아무거나로 들어가 "내 단어" 탭 → "예시 단어 불러오기"를 누른다. 지도에 노드와 연결선이 나타나면 정상이다.
2. 나가기 후 학번 칸에 `teacher`를 넣고 시작하면 예시 학생 12명으로 교사 화면이 열린다. 워드클라우드와 포트폴리오를 확인한다.
3. `API_URL`을 넣은 뒤에는 실제 학번 대신 가상의 학번(예: `9901`)으로 접속해 단어를 넣고, 시트에 행이 생기는지와 헤더의 저장 표시가 "서버 저장됨"으로 바뀌는지 확인한다. 같은 학번을 다른 이름으로 접속했을 때 거부되는지도 확인한다.
4. 확인이 끝나면 시트에서 테스트 행을 지운다.

## 오류 메시지

| 화면 표시 | 원인 |
|---|---|
| 이 학번은 다른 이름으로 등록되어 있어요 | 학번에 묶인 이름과 다름. 시트 B열 확인 |
| 교사 비밀번호가 틀렸어요 | `TEACHER_PIN`과 불일치 |
| Code.gs에서 TEACHER_PIN을 설정한 뒤 다시 배포하세요 | 비밀번호를 비워 둔 채 배포함 |
| 서버 연결 실패 — 기기 저장본 사용 | 웹앱 URL 오류, 배포 권한이 "모든 사용자"가 아님, 또는 네트워크 문제 |
